# Background music sources

## Active chill soundtrack

Downloaded 2026-10-12 from OpenGameArt:

| Runtime file             | Original title / author                         | Source and license                                                             |
| ------------------------ | ----------------------------------------------- | ------------------------------------------------------------------------------ |
| `menu-calm-loop.mp3`     | Calm Loop / wipics                              | <https://opengameart.org/content/calm-loop> — CC0 / public domain              |
| `kitchen-chill-loop.mp3` | Chill (Loopable) / Pro Sensory (Alex McCulloch) | <https://opengameart.org/content/chill-loopable> — CC0; author requests credit |

The menu uses a quiet ambient loop. All five restaurants share a mellow low-fi loop, replacing the prior dramatic, bouncy and rhythmic venue-specific score. Both files are MP3 for broad iOS/Safari compatibility. Tracks load after the first user gesture, crossfade on menu/game transitions and retain only the active decoded buffer. A slower, quieter synthesized fallback remains available if a browser cannot decode a track. Existing action SFX are unchanged.

The previous venue-specific OGG loops below are no longer referenced by the runtime. They remain in the asset directory; no source files were deleted.
