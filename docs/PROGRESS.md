## Sửa lỗi khởi động game trên iPhone/Zalo (2026-10-12)

- Ảnh cập nhật của người dùng cho thấy WebGL đã qua bước khởi tạo; exception thật là `Cannot merge vertex data that do not have the same set of attributes`. Nguyên nhân là hai đường batching (`batchStatic` của scene và gộp bộ phận mèo) chỉ nhóm theo material, trong khi Babylon yêu cầu nguồn merge còn phải có cùng vertex streams.
- Sửa batch key thành material + tập vertex attributes; nhóm không tương thích được merge riêng. Lỗi một batch phụ không còn chặn toàn bộ scene: các mesh nguồn và shadow caster được giữ lại, warning chỉ ghi local console. Đổi tiêu đề màn lỗi khởi động thành nội dung trung tính; chỉ hiện hướng dẫn WebGL theo nền tảng khi exception thực sự nhắc tới WebGL/context.
- Giữ màn khôi phục cho lỗi WebGL thực: trên iPhone gợi ý mở link bằng Safari, có sao chép URL/tải lại và chi tiết lỗi escape HTML lưu trên thiết bị. Không gửi telemetry, không đổi engine, độ phân giải, gameplay hoặc Multiplayer.
- Kiểm chứng lượt này: production build (typecheck, Vite client, esbuild server), Prettier cho các file sửa và `git diff --check` đạt. Không chạy unit/E2E theo hướng dẫn hiện hành. Chưa thể xác nhận trên iPhone thật; người dùng cần tải lại build mới để kiểm tra scene hiện lên.

## Cách xác minh Giai đoạn 4.1 khi có PostgreSQL

Tạo một database kiểm thử biệt lập có tên chứa `test`, rồi chạy từ PowerShell:

```powershell
$env:ACCOUNT_TEST_DATABASE_URL='postgres://kitchen:password@localhost:5432/kitchen_test'
$env:DATABASE_URL=$env:ACCOUNT_TEST_DATABASE_URL
npm.cmd run db:migrate
npm.cmd run db:seed
npm.cmd run test:db
$env:E2E_ACCOUNT_DATABASE_URL=$env:ACCOUNT_TEST_DATABASE_URL
$env:VITE_SAME_ORIGIN='true'
npm.cmd run build
$env:E2E_PRODUCTION='true'
npx.cmd playwright test tests/e2e/account.spec.ts
```

Không trỏ `ACCOUNT_TEST_DATABASE_URL` tới database có dữ liệu người chơi; integration suite yêu cầu tên database có `test` và xóa hồ sơ/match fixture do nó tạo.

Với Compose: đặt `POSTGRES_PASSWORD`, sau đó `docker compose up --build`. Compose chạy migration + seed trước server; server đọc `DATABASE_URL`. Thao tác này chưa được xác minh trong môi trường hiện tại.
